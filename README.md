# SCHLPUBRUL

학칙공단(학칙·공단정관·공공기관) 수집 데이터

## 출처 및 라이선스

- **원천 데이터**: 법제처 국가법령정보센터(https://www.law.go.kr) — 국가법령정보 공동활용 OpenAPI(https://open.law.go.kr)를 통해 수집.
- **저작권**: 학칙·공단정관·공공기관 규정은 법령과 달리 개별 기관(대학·공단·공공기관)에 저작권이 있을 수 있다. 법제처가 공개 제공하는 자료를 수집한 것이며, 이용·재배포 시 출처(법제처 국가법령정보센터)를 표기하고 개별 기관의 권리를 존중해야 한다.
- **유의**: 이 저장소의 JSON/MD 는 원천을 기계 가공한 수집 시점 스냅샷이며 법적 효력을 갖는 원본이 아니다.
